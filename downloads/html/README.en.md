# Single-file HTML downloads

[简体中文](README.md) · [繁體中文](README.zh-TW.md) · English

Click a link below to download the `.html` file directly. Once it has downloaded, open it from your browser's downloads list or file manager. There is no need to copy source code or change the extension.

| File | How to use it |
| --- | --- |
| [Download archcase.html](https://github.com/guopuxin09-afk/ArchCase/releases/download/html-2026-10-13/archcase.html) | Open in a browser. Map libraries and world overview data load from jsDelivr, with unpkg as a fallback. An internet connection is required. |
| [Download archcase-offline.html](https://github.com/guopuxin09-afk/ArchCase/releases/download/html-2026-10-13/archcase-offline.html) | Open in a browser. Libraries, the world overview, and all 221 case entries are embedded for offline use. |

Both versions share the same case data and interface. Primary case links open Markdown study notes in this repository; optional links to original Notion notes may require access permissions.

The collection's content is available as [Markdown files](../../notes/README.md). The interactive HTML map is one way to browse it. You can also read the Markdown files directly or import them into Notion, Obsidian, or other tools.

The offline version supports search, category filters, map markers, the world overview, and theme and language switching. Street maps, complete GitHub case notes, original Notion notes, and nearby maps still require an internet connection. Some markers represent city centers; check original sources for precise locations.

Support for opening local HTML files varies between mobile browsers. On phones, the installable [website / PWA](../../web/README.md) or [Android APK](../../android/README.en.md) may be more convenient. The PWA guide and document import guide are currently in Chinese.

The offline file is generated by `web/scripts/build-standalone.cjs` and includes third-party license notices. After editing the map source, run `npm run build:standalone` in `web/` to regenerate it. When publishing a new version, attach both HTML files to a new Release and update the download links in all three languages.
