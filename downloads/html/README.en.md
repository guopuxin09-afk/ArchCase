# Single-file HTML downloads

**On iPhone / iPad, open the [public web app](https://archcase-iphone-atlas.cuddlyshell7.chatgpt.site) in Safari, then use Share → Add to Home Screen.**

| File | How it works |
| --- | --- |
| [Download archcase.html](https://github.com/guopuxin09-afk/ArchCase/releases/download/html-2026-10-13-ios/archcase.html) | Map code, the world overview and all 221 cases are embedded. It tries online streets after startup; the interactive overview remains available if the street service fails. |
| [Download archcase-offline.html](https://github.com/guopuxin09-afk/ArchCase/releases/download/html-2026-10-13-ios/archcase-offline.html) | Starts with the embedded overview, without waiting for a connection. Search, categories, markers, details, language and theme work offline. Select “Load street map” for online street detail. |

These links download HTML directly. No copying source code or renaming extensions is needed. On a computer, open the file in a browser.

The iPhone / iPad Files preview may not run JavaScript. These files provide a static world map, an index of all 221 cases and an “Open web app” link without scripts. Static preview does not support search, filtering or map panning. A local HTML viewer that supports scripts may run the interactive version; capabilities depend on the app.

“World overview ready. The street service cannot be reached” means the base map is working but online streets are unavailable. The overview contains country outlines, not offline streets. Street tiles, complete GitHub notes, original Notion notes and nearby maps require a connection. Some coordinates are city centers; check original sources.

Primary case links in both HTML files open this repository's Markdown notes. The [public web app](https://archcase-iphone-atlas.cuddlyshell7.chatgpt.site) is the author's separately hosted PWA; its original Notion notes may require access permissions. Public notes are also available as [Markdown files](../../notes/README.md).

Both files are generated by web/scripts/build-standalone.cjs, including third-party license notices. Run npm run build:standalone in web/ to rebuild both. Attach both files to a Release and update the download links in all three languages.

Validation: desktop Chromium, 390px phone and 820px tablet widths, script-blocked previews, and interactive overview/search with all external networking blocked. This does not replace testing on actual iPhones or iPads.
