## 在 GitHub 阅读

从上面的索引进入分类或条目。各分类的 README 提供可点击的文件列表，方便在 GitHub 浏览。

原始文件保留 YAML 属性、别名、标签、来源链接，以及 `[[条目名称]]` 形式的 Wiki 关系。GitHub 不会把这种关系语法自动转换为可点击链接；这不影响正文和来源链接的阅读，条目之间的查找可借助分类与建筑师索引。

## 下载与导入笔记工具

可以下载整个仓库，或把两个目录一起复制到自己的资料目录。这些 MD 文件也可导入 Notion，或放入 Obsidian 使用；这里提供的是通用文档，没有附带插件、账户设置或个人工作区配置。

各平台对目录、YAML 属性、标签、别名及 Wiki 关系的读取方式不同，导入后的关系显示不一定与原文件相同，可能需要补设属性、调整页面结构或改写链接。导入后请自行检查；这里不承诺跨平台无损迁移，也不会自动与地图同步。

本次只公开这两个目录。原文件还有 222 处关系，指向完整笔记集中的 52 个空间策略、建筑理论或哲学条目；它们未包含在这次发布中。无论使用哪一种阅读工具，缺少这些目标文件时，都不能形成完整的关联阅读。参见[收录范围](../docs/collection-scope.md)。

## 如何使用这些文件

可以先按建筑类型或地点找到案例，再阅读建筑师条目与原始来源，最后结合平面、剖面、场地及使用方式做自己的分析。文字摘要与分类是学习入口，部分条目仍有待补充或核实。课程引用时，请回到条目列出的原始资料并注明来源。

本次保留 305 篇原始 MD 文件的字节内容，没有补写未经核实的事实。网页地图的数据快照与 Markdown 文件的更新需要分别维护。
