## 在 GitHub 閱讀

從上面的索引進入分類或條目。各分類的 README 提供可點選的檔案列表，方便在 GitHub 瀏覽。

原始文件保留 YAML 屬性、別名、標籤、來源連結，以及 `[[條目名稱]]` 形式的 Wiki 關係。GitHub 不會把這種關係語法自動轉換為可點選的連結；這不影響正文與來源連結的閱讀，條目之間的查找可透過分類與建築師索引。

## 下載與匯入筆記工具

可以下載整個儲存庫，或把兩個目錄一起複製到自己的資料目錄。這些 MD 文件也可匯入 Notion，或放入 Obsidian 使用；這裡提供的是通用文件，沒有附帶外掛、帳戶設定或個人工作空間設定。

各平台對目錄、YAML 屬性、標籤、別名及 Wiki 關係的讀取方式不同，匯入後的關係呈現不一定與原文件相同，可能需要補設屬性、調整頁面結構或改寫連結。匯入後請自行檢查；這裡不承諾跨平台無損移轉，也不會自動與地圖同步。

本次只公開這兩個目錄。原文件還有 222 處關係，指向完整筆記集中的 52 個空間策略、建築理論或哲學條目；它們未包含在這次發布中。無論使用哪一種閱讀工具，缺少這些目標檔案時，都無法形成完整的關聯閱讀。參見[收錄範圍](../docs/collection-scope.zh-TW.md)。

## 如何使用這些文件

可以先按建築類型或地點找到案例，再閱讀建築師條目與原始來源，最後結合平面、剖面、場地及使用方式做自己的分析。文字摘要與分類是學習入口，部分條目仍有待補充或核實。課程引用時，請回到條目列出的原始資料並註明來源。
