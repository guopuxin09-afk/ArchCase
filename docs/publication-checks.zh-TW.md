## 程式與建置

- 221 個案例的主要詳細資料連結全部對應到儲存庫中真實存在的 Markdown 檔案；可選的 Notion 來源單獨標示權限。
- 公開主連結驗證只接受內嵌的 GitHub 案例 URL 集合，並檢查 HTTPS、帳戶、儲存庫與路徑；異常通訊協定、其他網域名稱、憑證、連接埠、查詢參數和路徑變體被拒絕。
- PWA 移除私人託管設定和本機絕對路徑。獨立目錄中僅用公開原始碼和打包資源建置成功，31 個產生檔案逐一位元組對應。
- PWA 在 `/ArchCase/` 子路徑完成 22 項應用程式資源快取後，實際斷網重新載入、世界概覽、案例搜尋、詳細資料索引和主題／語言切換可用。
- Android 網頁資源從公開專案重新整合與建置，獨立重現的 28 個資源逐一對應。
- Android APK 從公開版本原始碼重新編譯，APK v2 簽章驗證通過，28 個內嵌網頁及授權資源逐一與建置結果比較 SHA-256；版本 1.0.1、versionCode 2、套件名稱 `com.archcase.atlas`、最低 API 24、目標 API 36。
- Android 網頁在 Chromium 的 390×844、360×640、844×390、1280×800 尺寸下檢查，阻止全部外部請求時，世界概覽、221 個案例、搜尋、分類、語言、主題與詳細資料索引可用；未發現 JavaScript 錯誤或水平溢出。
- 單一檔案離線 HTML 使用本機 `file://` 開啟，阻止外部請求後，世界概覽、案例搜尋與詳細資料索引可用。
- 第三方執行所需函式庫保留授權文字，APK 補入 Capacitor MIT 授權與已辨識原生組件的 Apache 授權和來源說明。

## 檢查邊界

沒有逐條複核所有建築事實或全部外部來源，沒有進行完整的漏洞、隱私或第三方權利稽核。沒有在 Android 實機／模擬器安裝執行，也沒有驗證真實 iPhone 的 Safari 主畫面安裝、鍵盤、系統列和手勢行為。瀏覽器驗證不能替代這些裝置驗證。

`scripts/check-publication.cjs` 可檢查快照清單、數量、公開詳細資料目標、相對 Markdown 連結、APK 雜湊值，以及已知憑證模式和本機設定檔案的混入。靜態模式檢查發現零匹配，不構成不存在任何敏感資訊的保證。

```sh
node scripts/check-publication.cjs
```

APK 的最後下載雜湊值見 [`android/apk/archcase-debug.apk.sha256`](../android/apk/archcase-debug.apk.sha256)。完整使用邊界見 [使用與資料說明](../DISCLAIMER.zh-TW.md)。
