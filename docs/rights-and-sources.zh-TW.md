## 原創程式碼

儲存庫根目錄的 MIT 授權適用於本專案原創的程式邏輯和相關開發說明，包括網頁互動、PWA 建置與快取程式碼、Android 封裝程式碼以及由維護者編寫或經 Codex 產生整理的建置工具。使用 MIT 程式碼時請保留授權與著作權聲明。

這裡的“原創程式碼”不包括相依套件目錄中原作者發布的檔案，也不將內嵌案例資料自動視為程式碼授權。由 AI 產生程式碼這一事實已在 README 中公開說明。

## 筆記與案例資料

`notes/` 和資料檔案中的案例資料是個人學習筆記與來源索引，本次公開供閱讀、學習與參考，**未為全部筆記和資料授予統一的 MIT 或 Creative Commons 授權**。維護者能夠授權的原創內容與第三方資料需要分別判斷。

建築名稱、事實資料、引用文字及解釋的權利性質可能不同。若要再出版、批量再散布或商業使用，請自行核實所使用內容的權利與授權；引用時請回到原始來源，並註明具體作者與頁面。本次公開不表示維護者擁有所有來源材料的著作權。

本次兩個原始筆記目錄沒有圖片附件或圖片嵌入。所有 221 篇案例筆記至少有一個外部來源連結，部分建築師筆記仍缺少外部出處。來源說明不是完整的事實或授權稽核。
