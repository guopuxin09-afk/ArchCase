## 程序与构建

- 221 个案例的主要详情链接全部对应到仓库中真实存在的 Markdown 文件；可选的 Notion 来源单独标注权限。
- 公开主链接校验只接受内嵌的 GitHub 案例 URL 集合，并检查 HTTPS、账户、仓库与路径；异常协议、其他域名、凭据、端口、查询参数和路径变体被拒绝。
- PWA 移除私人托管配置和本机绝对路径。独立目录中仅用公开源码和打包资源构建成功，31 个生成文件逐个字节对应。
- PWA 在 `/ArchCase/` 子路径完成 22 项应用资源缓存后，实际断网重载、世界概览、案例搜索、详情索引和主题／语言切换可用。
- Android 网页资源从公开工程重新集成与构建，独立复现的 28 个资源逐个对应。
- Android APK 从公开版本源码重新编译，APK v2 签名验证通过，28 个内嵌网页及许可资源逐个与构建结果比较 SHA-256；版本 1.0.1、versionCode 2、包名 `com.archcase.atlas`、最低 API 24、目标 API 36。
- Android 网页在 Chromium 的 390×844、360×640、844×390、1280×800 尺寸下检查，阻止全部外部请求时，世界概览、221 个案例、搜索、分类、语言、主题与详情索引可用；未发现 JavaScript 错误或横向溢出。
- 单文件离线 HTML 使用本地 `file://` 打开，阻止外部请求后，世界概览、案例搜索与详情索引可用。
- 第三方运行库保留许可文本，APK 补入 Capacitor MIT 许可与已识别原生组件的 Apache 许可和来源说明。

## 检查边界

没有逐条复核所有建筑事实或全部外部来源，没有开展完整的漏洞、隐私或第三方权利审计。没有在 Android 真机／模拟器安装运行，也没有验证真实 iPhone 的 Safari 主屏幕安装、键盘、系统栏和手势行为。浏览器验证不能替代这些设备验证。

`scripts/check-publication.cjs` 可检查快照清单、数量、公开详情目标、相对 Markdown 链接、APK 校验和，以及已知凭据模式和本地配置文件的混入。静态模式检查发现零匹配，不构成不存在任何敏感信息的保证。

```sh
node scripts/check-publication.cjs
```

APK 的最终下载校验和见 [`android/apk/archcase-debug.apk.sha256`](../android/apk/archcase-debug.apk.sha256)。完整使用边界见 [DISCLAIMER.md](../DISCLAIMER.md)。
