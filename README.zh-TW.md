# ArchCase · 建築案例積累庫

[简体中文](README.md) · [繁體中文](README.zh-TW.md) · [English](README.en.md)

這是在大學初期逐漸累積的建築案例庫，收集經典與個人喜愛的作品，希望幫助剛進大學的建築系學生，以及對建築感興趣的愛好者，發現、閱讀與整理案例。

**先選資料，再選使用方式**：案例、建築師與 T100 是資料內容；MD 文件與互動地圖是閱讀入口，HTML、PWA 和 APK 是地圖的不同使用形式。

## 1. 資料內容與閱讀入口

| 資料 | 內容 | 從這裡開始 |
| --- | --- | --- |
| 建築案例 | 221 件作品，依 12 類整理 | [依建築類型瀏覽](notes/00%20Cases/README.zh-TW.md) |
| 建築師與事務所 | 83 個條目，另附普立茲克索引 | [建築師索引](notes/01%20Architect/README.zh-TW.md) |
| T100 個人精選 | 以 20 世紀重要作品為主，包含少量 21 世紀案例 | [T100 閱讀索引](notes/T100.zh-TW.md) |
| 全部 MD 文件 | 305 篇原始筆記，可下載、閱讀與繼續整理 | [文件目錄與匯入說明](notes/README.zh-TW.md) |

**T100 是什麼**？這是我個人整理的一組建築精選，最初希望選出自己認為對 **20 世紀建築重要的約一百件作品**，也納入了少量 21 世紀案例。它是一條帶有個人判斷、會持續調整的閱讀線索。本次快照有 **101 篇帶 T100 標籤的案例筆記**，標籤名稱沿用最初選集的概念。

分類包括文化、教育、體育、飯店、醫療、工業與基礎設施、商業與辦公、公共、宗教、居住、改造與景觀。`04 酒店建筑` 目前是空的預留分類；作品也可能同時具備多種屬性。統計以 **2026-10-13** 公開快照為準。

不知道從哪裡開始時，可以先從 T100 挑幾件感興趣的作品，再沿著建築師、類型與原始來源繼續閱讀。做課程設計時，也可以從同類機能、相似基地或具體空間問題查找，不必先記住所有名字。

## 2. 選擇地圖版本

**第一次使用，建議先下載離線 HTML，用電腦瀏覽器開啟**。 想在 Android 上安裝使用，可選擇 APK；希望自行架設網頁或加入手機主畫面，可使用 PWA 檔案。

| 版本 | 取得方式 | 適合的用法 |
| --- | --- | --- |
| 離線 HTML | [下載 archcase-offline.html](https://github.com/guopuxin09-afk/ArchCase/raw/refs/heads/main/downloads/html/archcase-offline.html) | 單一檔案，下載後用瀏覽器開啟；內建地圖執行資源 |
| 聯網 HTML | [下載 archcase.html](https://github.com/guopuxin09-afk/ArchCase/raw/refs/heads/main/downloads/html/archcase.html) | 單一較小檔案，開啟時需要連網載入部分資源 |
| 網頁 / PWA | [網頁檔案與部署說明](web/README.zh-TW.md) | 將 `web/dist/` 放到靜態網站；在支援的瀏覽器中安裝或加入主畫面 |
| Android APK | [下載 archcase-debug.apk](https://github.com/guopuxin09-afk/ArchCase/raw/refs/heads/main/android/apk/archcase-debug.apk) · [安裝說明](android/README.zh-TW.md) | Android 7.0 以上的體驗版，目前為 Debug 建置 |

GitHub 的檔案預覽頁只顯示 HTML 原始碼。若點擊後看到程式碼，請使用檔案頁的 **Download raw file（下載原始檔案）** 儲存，再用瀏覽器開啟。本儲存庫提供網頁檔案；PWA 部署步驟請見上方說明。

離線 HTML、APK，以及首次成功快取後的 PWA，可以離線使用**世界概覽、案例索引、搜尋與分類**。街道底圖、GitHub 案例全文與外部來源仍需連網。若要離線閱讀完整筆記，請同時下載 MD 文件。手機對本機 HTML 的支援可能不同；iPhone 可透過 HTTPS 網站使用 PWA。

## 3. 地圖怎麼用

1. **搜尋作品**。輸入建築名稱、建築師、地點、年份或標籤，例如 `Barcelona`、`T100`。
2. **篩選分類**。勾選一種或多種建築分類，清單與地圖會同步篩選；點擊「查看全部结果」，讓目前的結果進入視野。
3. **瀏覽地圖**。拖曳地圖，用 `+` / `−` 縮放；點擊帶數字的圓點，展開該處聚集的案例。
4. **開啟資訊卡**。點擊清單中的作品或單一地圖標記，查看案例資訊。點擊清單作品時，地圖會自動定位。
5. **繼續閱讀**。點擊「阅读案例笔记 ↗」開啟本儲存庫的 MD 全文；點擊「查看周边地图 ↗」了解周邊位置。

想恢復全部案例，請**清除搜尋詞，並全選分類**。右上角可以切換中文 / 英文及明暗主題。手機可拖曳或點擊底部索引把手展開清單，桌面可收起篩選欄。另有[手機介面預覽](web/screenshots/mobile.png)。

地圖中的主要詳細資訊連結已對應本儲存庫筆記，另保留選用的原始來源筆記入口。部分標記是城市或區域級的近似位置，實地走訪前請確認準確地址與開放情況。

## 4. 下載文件與匯入筆記軟體

儲存庫頂部的 **Code → Download ZIP** 可下載全部檔案。解壓縮後，學習文件位於：

- `notes/00 Cases/`：建築案例，依類型分目錄。
- `notes/01 Architect/`：建築師、事務所與普立茲克索引。
- `notes/T100.md`：T100 個人精選的閱讀入口。

MD 檔案可以直接閱讀，也可以依工具的匯入方式放入 **Notion、Obsidian 等筆記軟體**。建議把案例與建築師兩個目錄一起匯入。不同工具對 YAML 屬性、標籤、別名與 `[[Wiki 連結]]` 的支援不同，可能需要調整格式或關聯；詳見[文件說明](notes/README.zh-TW.md)。

也有 [Notion 版本](https://app.notion.com/p/3f4bdfcd663381a3aa5ed0267d6d283a)，能否存取取決於對應頁面的分享權限。GitHub 提供公開快照，兩個版本可能有更新差異。

305 篇原始筆記保留現有名稱、正文、標籤與來源，內容有詳有略。本次僅公開案例與建築師兩個原始目錄，未包含其他理論、策略與哲學條目，也未匯出 Notion 的額外圖片。原文中指向其他目錄的關聯仍然保留；具體範圍請見[收錄說明](docs/collection-scope.zh-TW.md)。README 提供簡體中文、繁體中文與英文；其他儲存庫說明與使用文件提供簡繁雙語，原始學習筆記維持現有語言。
